# ELLO Cinematic + Firebase

Versão 2 do protótipo ELLO, mantendo o visual cinematográfico e adicionando a infraestrutura real de Firebase.

## Rodar imediatamente
```bash
npm install
npm run dev
```

O visual continua funcionando localmente mesmo antes de configurar Firebase.

## Ativar nuvem
Leia `GUIA-FIREBASE.md`, crie `.env` e configure Firebase Authentication, Firestore e Storage.

## Incluído
- Interface cinematográfica responsiva
- Fluxo completo de cápsula
- QR e link
- Contagem regressiva
- Abertura e reação
- Firebase SDK
- Auth anônimo/Google
- Firestore
- Storage/uploads
- Regras de Firestore
- Regras de Storage
- Índice Firestore
- Firebase Hosting
- Serviços para criar/listar/abrir/reagir

## Ainda depende de credenciais/serviços externos
- Configuração real do seu Firebase
- E-mail transacional/push
- IA
- Gateway de pagamento
